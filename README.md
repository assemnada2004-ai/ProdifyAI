# Prodify AI — Android v1

نسخة أولى حقيقية لواجهة تطبيق Android باسم Prodify AI.

## ما تم بناؤه
- شاشة رئيسية وهوية Prodify AI.
- اختيار صورة من الهاتف.
- شاشة إعداد الإعلان.
- اختيار نوع الإعلان ووصف إضافي.
- شاشة نتيجة/معاينة.
- واجهة عربية مناسبة للـRTL مع هوية داكنة بنفسجية/سماوية.
- لا توجد مفاتيح API داخل التطبيق.
- compileSdk/targetSdk = 36.

## الخطوة التالية
استبدال وضع التجربة بمحرك AI حقيقي عبر Backend آمن:
1. التطبيق يرفع الصورة إلى الخادم.
2. الخادم يرسل الطلب إلى مزود توليد الصور.
3. الخادم يرجع الصورة الناتجة للتطبيق.
4. إضافة تسجيل الدخول، الحصص، والدفع قبل النشر التجاري.

## فتح المشروع
افتح مجلد `ProdifyAI` في Android Studio ثم Sync/Build.
